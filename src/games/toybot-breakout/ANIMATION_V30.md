# V30 独立机甲动作

本轮针对身体叠影、跑动被开火打断、远程机型像挥刀三个问题重做动作路径，并一并完成 V29 参考画风接入。

## 动作和状态

- `pulseAnimation.ts`：稳定单手向前持枪跑动，首领战使用扣扳机、短促后坐力、复位；不使用挥刀动作。
- `heavyAnimation.ts`：负重持炮跑动，首领战使用蓄能、发射、重后坐力、回正，时序独立于轻型枪。
- `bladeAnimation.ts`：低位持剑跑动，只有真实攻击窗口才进入拔刀、命中、收刀；命中节奏跟随已捕获的近战飞行时间，包含终结斩。
- `animationModules.ts` 按机型分派。每台机甲只有一个身体节点；删除上半身叠图和闪避分身。换图集不做透明交叉混合，避免两个完整身体同时出现。
- 每个机型独立的 16 帧跑动循环 × 基础/强化两档；独立动作图集为 8 帧 × 跑动兼容、站定、攻击、闪避 × 两档。首领战不会继续跑动。低动态模式停在单帧。
- 攻击间隔、目标选择、伤害和换道判定未因动作素材改变。空场无伤害曳光弹延长 3 个逻辑步，避免两轮射击之间完全看不到飞行；有目标的命中时间不变。

## 素材与复现

AI 原图在 `art-source/mech-{pulse,heavy,blade}-{motion,run}-v30.png`，透明运行图在 `public/games/toybot-breakout/optimized/` 对应同名文件。全部已接入，非展示用概念图。提示词见 `ART_PROMPTS_V30.json`。

运行 `optimize-run-v30.ps1` 会先生成动作图，再生成跑动图。脚本仅进行缩放、逐格裁切和整格平移注册，保留 AI 绘制的肢体，不合成新的肢体。模板匹配把背部核心作为统一锚点；跑动图测得水平锚点偏差 0–1 px，动作图 3–5 px，转身仍有少量自然位移。登记结果见两个 `*-registration-v30.json`。

## 验证

本地浏览器检查三种机型及跑图/首领战：3 台机体对应 3 个身体、0 个上半身叠图/闪避分身；使用各自的 V30 图集。399×711、390×844 和默认视口检查，无水平溢出，展开换道按钮可切换第 3 队列。绘制监视现场约 56–57 Hz，仅为本机观察，非移动设备性能承诺。浏览器无运行错误，有 React Router 未来版本提示。Facebook 真机尚未验收。
