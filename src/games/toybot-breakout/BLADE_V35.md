# V35 近战挥刀动作

原有挥刀用少数几帧并长时间停在同一姿势。新专属图集为每个装备档提供16帧独立动作（共32帧）：低架防御、屈膝蓄力、转腰拔刀、单手斜斩、重心前移、收刀。每帧只绘制一台实体机甲，不做角色双图交叉淡入，也不复制枪械的后坐动作。

`bladeMotionV35.ts` 将挥刀接触点对应到实际刀波的飞行时长；终结斩和核心技能使用自身接触时刻。收刀末帧提前进入显示窗口，避免只播放到倒数第二帧。射速、伤害、距离、命中判定保持现有规则，闪避和跑动保持各自独立动作。

AI原图和透明修正版位于art-source，提示词保存于BLADE_PROMPT_V35.json。optimize-blade-v35.py只做图格尺寸归一化，运行时RGBA图集1024×512，约495KB。

验证：260项测试通过；新增完整16帧序列遍历、动作不修改战斗状态、减少动态模式与透明图集校验；ESLint通过，生产构建通过。TypeScript无游戏新增错误，共享App.tsx和LogService.ts既有3处错误仍在。390×844本地浏览器实际观察普通近战与核心技能、新图集来源、独立单体姿势及首领扣血，控制台无error；普通近战实机截图录成48帧动图。未进行Facebook真机环境验收。
