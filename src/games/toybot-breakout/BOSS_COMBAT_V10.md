# 首领技能与八帧战斗动作（2026-11-05）

本版以 bossSkills.ts 的三技能组为准，替换旧的炮击/冲撞循环。BOSS_FLOW.md 中早期技能顺序作为历史记录。

## 五关技能

| 首领 | 技能组 | 主要决策 |
| --- | --- | --- |
| 铸炉监工 | 地脉熔喷、熔池封路、熔岩封路 | 看地面预警；喷口按列轮换，每次轮换重新预警。熔池保留热区，二阶段可封两列，熄灭后再回到输出轨道 |
| 苍穹蜂后 | 蜂巢孵化、蜂后汲能、蜂群出击 | 射击蜂卵阻止孵化；漏掉的卵会产生可攻击小机器人。汲能蜂每秒恢复首领3点生命，击破后停止；不会超过最大生命 |
| 赤铁堡垒 | 双塔护阵、移动盾墙、重盾封锁 | 两个护盾塔存活期间首领减伤，先拆塔再打核心；移动盾墙可以击破或换道。取消通用身体冲撞 |
| 风暴先知 | 导电核心、极性轮转、风暴巡航 | 导电核心维持另外两列电场，击破核心立刻关闭电场；极性和风暴逐列轮转，每次变化前重新预警 |
| 星核帝皇 | 王权符印、三重裁决、星核交叉炮 | 符印提供保护，限时击破可解除保护并取消该符印爆发；裁决连续三轮改变安全列，三轮都独立预警；交叉炮作为其单独的一项技能保留 |

所有正常技能组不再使用 cannon/rush/sweep/burst。新技能通常预警2秒；极性/裁决1.6秒。攻击列在预警后锁定，换列必须先结束旧效果并重新预警，不追踪玩家。一次最多覆盖两条危险轨道。

蜂卵、汲能蜂、护盾塔、导电核心、符印是可射击目标；移动盾墙也可破坏。弹道继续使用轨道、实体ID和真实位置进行判定，不通过点击按钮直接删除。孵化生成新ID，不沿用已击破的卵。进入二阶段只在当前技能结束后的安全边界发生。

首领恢复期可随机换列；施法期间不会突然换列。最终首领的生命预算适度降低，为拆符印和换道留下时间。15组代表配置模拟为72.0–166.2秒；三机型固定5台/W3配置为63.5–114.5秒。永久满改装仍可更快，不反向增加首领生命。

## 玩家战斗姿态与闪避

- 道路阶段使用跑步表现；首领登场、战斗、转阶段和胜利场景使用背面战斗精灵，停止跑步帧及跑动颠簸。
- 脉冲、重装、疾刃各有8列×3行：待机、攻击、侧向闪避各8帧。待机双脚站稳，攻击包含准备、发力、后坐和收势。首领施法图集扩为8列×5行，每名首领8帧。
- 单列侧移0.4秒；前半段受击轨道仍为出发列，后半段改为目的列，画面按同一进度平滑过渡。连续输入不会刷新计时或获得整段无敌。
- 跨两列请求缓存为两次相邻侧移，避免瞬移，也不丢失长拖拽的目标。暂停冻结侧移计时和图集动画。
- 侧移期间暂不产生新攻击，旧炮弹仍按原轨道飞行；落地后恢复原有攻击节奏。每台机甲的炮口起点仍来自自身编队位置。
- 残影、脚底推进光和侧移音效跟随移动。只有真实攻击打到已离开的出发列，才显示局部“闪避”文字并播放确认音，不把普通换道伪装成成功闪避。
