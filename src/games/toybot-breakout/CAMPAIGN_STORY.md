# 随游玩展开的动态剧情 v12

## 正式游戏中的流程

1. 首页直接准备出击，序章漫画保留为回看入口。新玩家仍先走原有训练流程。
2. 入关自动接入本章现场：火花进入区域，米可说明目标。连续分镜渐显并缓慢推镜。
3. 玩家选择“接应失联伙伴”或“同步维护航标”。选择只决定任务，尚不发奖励。跳过入场通信默认使用维护航标。
4. 道路推进期间，发光中继从远处接近，任务条标出所在轨道。必须由玩家换道驶过，分别获得机甲 +1 或护盾 +1，且只触发一次。接取线与奖励门同为 GATE_CONTACT_Y，另有 3 个纵向百分点的换道容错区；中继避开相邻障碍的轨道。
5. 完成或错过接应都会得到对应对白。错过不导致主线失败。道路中段介绍区域背景，首领第二阶段提供一次剧情通信；通信不暂停战斗，可关闭，不盖住换道按钮。
6. 真实进入首领区域时，守护者发出本章独有指令，火花回应。完成回应或跳过后，才开始原有首领入场与攻击预警。
7. 必须通过真实战斗获胜，原有击破动画、结算奖励和顺序解锁才会执行。随后展示守护者回收、城市恢复分镜；玩家可依次接通三个维护节点，将报告传回网络，也可随时跳过。
8. 第五章首次胜利展示黎明中枢重启与“主线完成”。重玩已通关区域改为维修巡查、残留封锁信号与复检完成对白。

## 状态边界

`campaignReducer` 包装原 `gameReducer`，不改写原战斗判定。分镜可见时拦截 TICK/MOVE_LANE，冻结道路、敌人、炮弹、伤害与冷却；全局暂停仍有效，恢复后继续同一个剧情节点。对应道路 CSS 动画也会冻结。

普通通信使用游戏时间计时，每条 7.5 秒；暂停或分镜期间不会消耗。剧情节点按本局记录，只触发一次。HOME、RESTART、NEXT_LEVEL 会初始化新一轮记录，不创建持久剧情货币或第二套关卡解锁存档。

维护节点同步只是战后互动，不创造第二次奖励、额外胜负条件或额外开关锁。真实胜利结算时记录权限，跳过和完整播放获得相同的永久奖励。支援接应只影响本局伙伴或护盾。

## 新增美术

使用内置 ImageGen，5 张六格连续分镜图集，共 30 个画面：每章各有进场、通信、恢复三个双帧段。使用一次渐显转换与推镜，不反复闪烁两个跑步姿势。首领对话还使用现有八帧施法图集。遵循系统减少动画偏好。

- 源图：`art-source/chapter-film-{1..5}-v12.png`；部署图：`public/games/toybot-breakout/optimized/chapter-film-{1..5}-v12.jpg`。
- 图集均为两列三行，前三章运行尺寸 1024×1536，后两章为 1024×684；界面按各自画格比例呈现，避免拉伸。
- 中继：`art-source/story-relay-v12.png` 与 `optimized/story-relay-v12.png`；部署宽 256px，保留真实 alpha。
- 图集共约 2.32 MB，按当前关卡预取；不一次加载五套。
- 完整提示词：`art-prompts-v12.json`；重建支持已加入 `optimize-assets.ps1`。
