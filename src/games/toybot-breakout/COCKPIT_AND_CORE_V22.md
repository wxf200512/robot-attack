# 驾驶舱与核心解放 v22

## 实际变化

- 战斗底部改为驾驶舱，中央为 AI 绘制的装甲反应堆按钮；左屏显示生命与受击拖尾，右屏显示小队、护盾和装甲。下方三个 44px 高按钮换轨，继续支持原战场拖拽；驾驶舱内支持方向键与空格。首领蓄力、释放与反击窗口收进顶部通信读数，避免卡片遮住任务栏和首领。按钮由真正 HTML 控件实现，图片不承载文字与点击逻辑。
- 核心环展示充能，准备就绪亮起；激活后显示五秒倒计时和分机型色彩。未充满、暂停、剧情、战败等状态不能释放；所有换道按钮跟随原状态门控。
- 启动约 0.9 秒的全屏图集演出，持续阶段保留边缘能量和扫描；不拦截指针，不提供额外无敌。低画质/系统减少动态效果降低演出强度，暂停隐藏全屏覆盖并冻结技能时钟。
- 脉冲核心：从每台机甲自己的身体发射贯流束，使用现有三目标穿透结算与捕获轨道；不以全屏演出范围判定伤害。
- 力量核心：能量炮采用前向抛弧及独立旋转能量图，飞行较常态多两 tick，命中后才触发原同轨范围爆破；射击间隔不变。
- 近战核心：改为向前飞行的剑气，五 tick 抵达；释放后可侧闪，剑气继续攻击已捕获的同轨目标。常态近战仍须保持刀距与原轨道，核心仍只选延长刀距内最多三个目标。
- 对道路/召唤目标的核心伤害倍率提升为脉冲 1.6、力量 2、近战 1.6；首领倍率保留 1.25 / 1.2 / 1.15，防止仅靠数值骤减首领战时长。各机甲独立发射源、碰撞和伤害仍由模拟层管理。
- 适当缩短战场底部绘图区，给驾驶舱留出空间；背景、门、敌人和判定显示共享同一绘图区，未单独挪动角色或碰撞坐标。

171 项自动测试通过。使用无存档真实组件预览检查 390×844 与 320×667 手机驾驶舱、技能触发、独立光束、暂停门控和小屏布局；更新原两项技能到达时序测试，以真实弹体 duration 等待命中，剑气换道测试改为验证捕获轨道继续生效。新增前向抛弧、独立身体发射点、普通目标增伤/首领倍率和透明图集几何验证。

保留游戏目录隔离、原射击间隔和现有奖励流程。应用类型检查的 App.tsx / LogService.ts 三处共享错误不属于本轮改动范围。


## v23 整机与三轨修订（替代上文同轨核心规则）

- 清除机甲身旁的模块图标、融合悬浮挂件、独立武器贴片与头顶装备数字条；模块数值继续显示在驾驶舱。常态的整机升级原画保留，护盾仍按真实防御状态显示。
- 核心期间直接替换整台机甲的身体精灵：脉冲、力量、近战各有一张 4×4 觉醒图集，四行分别为跑动、待机、攻击、闪避。肩甲、背部能源和武器是机体的一部分。技能结束恢复当前等级常态机体，所有队员保持相同尺寸。
- 三种核心从每台机甲的真实发射点分别覆盖三轨。脉冲按轨穿透、力量按轨爆破、剑阵按轨选择最多三个目标；普通射击与常态近战仍只作用于本轨。已发出的弹体不会因玩家换轨而搬移；移动目标离开弹体捕获轨道仍会闪避该弹体。
- 核心输出允许边侧闪边释放，不改变基础射击间隔，不增加无敌。侧轨直接锁定首领的伤害为正面核心伤害的 60%，避免同一技能对主核的收益失控；道路与召唤目标正常获得三轨打击。
- 同一成员、同一轨、同一次横斩只绘制一条剑气，多目标伤害仍完整结算。每轮发射只扫描三次目标列表，不按成员重复扫描。光束长度按实际绘图区宽高计算，从身体中心准确连到目标；尺寸由 ResizeObserver 更新，无逐帧布局读取。
- 剧情通信与支援提示改在顶部；通信出现时暂时替代战术任务卡，关闭/结束后恢复。底部仅保留驾驶舱。顶部通信支持真实关闭操作，暂停与剧情演出仍遵守原状态门控。
- 使用内置 image_gen 生成三张整机原图；力量型额外通过 image_gen 清理白色背景。完整生成/编辑提示词在 ART_PROMPTS_V23.json、ART_EDIT_V23.json；源图在 art-source/mech-*-awaken-v23.png，白底原始版本另存为 mech-heavy-awaken-v23-raw.png。部署图在 public/games/toybot-breakout/optimized/mech-*-awaken-v23.png，均为 1024×1024 RGBA；optimize-v23.ps1 逐格缩放并添加透明边距。
- 主动核心的代表性首领战样本约 58–100 秒；为三轨技能更新旧的“其他轨永不受伤”测试，时间下限与既有组合配装回归一致为 55 秒，普通战斗仍保留原计时规则。
