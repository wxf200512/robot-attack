# 战斗体验升级 v21

本轮落实七项优化，继续沿用现有 AI 位图和精灵，不增加依赖或共享代码改动。

1. **分层打击反馈**：普通命中、装甲撞击、重炮、精英/部件破坏和首领解体采用不同尺寸、碎片和冲击环；装甲与精英补充分层音效。新增短时反馈队列，普通画质最多显示八组、低画质三组。轻量震屏为 1px，可在声音与画面设置关闭，系统减少动态效果时也关闭。
2. **怪潮节奏**：保留五关三波怪潮、双轨集群与撤离路线，调整队列生命分布，前排轻型试探、中央集群、后排较强掩护。保留末段补给间隙及原门的安全轨道规则；不增加每轮障碍文字播报。
3. **机型特色**：脉冲累计六次有效命中后，下轮齐射穿透一个同轨敌人，不增加对首领的直伤；换轨重置未完成聚焦。重炮常态溅射四单位纵深内至多两个同轨目标，伤害为主弹的 30%；核心爆发保留原范围与倍率。近战常态斩击两个刀距内同轨目标，额外常态目标只选道路敌人/首领召唤物，避免顺带伤害首领导致战斗过短。完美闪避与核心技能继续使用原反击和三目标规则。
4. **强化即时演出**：门的真实结算触发 1.2 秒非阻塞提示、能量汇入、装备标签展开与武器发光；原机甲/弹体升级素材立即同步。惩罚门采用不同色相，暂停时冻结，失败/进入首领区时清理。
5. **首领可读性**：增加蓄力、技能释放、调整站位和反击窗口指示与倒计时。首轮保留原教学节奏；后续收招为 2.4–3.2 秒，超载协议仍缩短。换位结束后才标记可反击。保持原技能组、锁定轨道、弹体抵达伤害与弱点倍率。
6. **动态空间**：沿用每关地图，加入慢速远景漂移、两档速度近景光迹和角色落地阴影；首领竞技场停用前进效果，只保留轻微环境浮尘。低画质和减少动态效果优先关闭装饰。
7. **结算与重试**：统计真实已结算输出、首领伤害、生命损失、盾甲吸收、道路碰撞与技能伤害；展示本局流派、首领剩余耐久或剩余路程，按主要损伤/部件破坏/核心使用给出改装建议。失败页把一键重试放在详细报告上方，手机首屏可触达。重试仍从本关开局、一个机甲开始，报告归零，不赠送奖励或重复解锁。
