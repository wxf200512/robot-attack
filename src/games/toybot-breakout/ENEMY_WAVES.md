# 五分钟关卡与主题前线（v24，2026-11-06）

当前配置以本节为准，后面的旧设计记录保留作历史参考。

每关采用“约两分钟前线推进 → 战前补给 → 约三分钟首领战”的结构，保留原有解锁顺序、剧情、机库与核心技能。推进速度为每100ms增加0.08进度，首领入口93/97对应116.3/121.3秒。暂停与剧情演出不计入推进时间；熟练走位、装备、补给和机库改装会影响实际首领用时，不设置强制等待或三分钟硬性失败。

## 两分钟前线节奏

- 0–25秒：外围侦察与初始成长门，介绍本关主要兵种。
- 约25–53秒：第一轮主题怪潮与第一名精英。
- 约54–86秒：混编怪潮、狙击/支援单位和第二名精英。
- 约87–107秒：终段怪潮、第三名精英和战前整备。
- 约116–122秒：清理道路对象与未完成的危险区，进入对应首领战。

怪潮与精英是道路上连续推进的遭遇段，不增加额外选关或每轮弹窗。保留旧三组编队，另加三组主题怪潮及三名精英护卫编队。每关总敌人数为119 / 147 / 176 / 203 / 230；弱怪潮占90 / 111 / 132 / 153 / 174只。无射击压力测试的可见预算为72个单位，正常清怪会减少数量。

## 精英技能与奖励

五类技能分别具有独立预警、弹体/光束和落地反馈：熔焰地雷、猎蜂扇射、重轨贯射、导电球场、禁卫交错炮。普通小怪维持原有一次攻击；精英在完整攻击与冷却结束后可再次施放。击破蓄力中的单位可打断，已发出的弹体和落地区域继续执行，不会因为源单位死亡而突然消失。

- 熔焰地雷：1.8秒预警、1秒飞行、2秒灼烧区。
- 猎蜂扇射：1.5秒预警，双轨三连射，留出一条空轨。
- 重轨贯射：2.4秒预警、0.2秒光束判定，高伤但可提前避让。
- 导电球场：1.8秒预警、1.2秒飞行、2.4秒导电区；持续伤害命中可短暂干扰。
- 禁卫交错炮：双轨预警，第二轨延迟0.5秒，不追踪玩家换道。

实际击破精英额外获得100+关卡序号×20分、30核心能量、8点修复和1份结算零件；核心激活期间仍不能自我充能。奖励按实际击破发放一次，错过精英不会自动领取。

编队生成检查重叠接触窗口；敌方攻击调度同时考虑即将到达的身体碰撞和补给轨道，保持至少一条撤离路线。屏幕上最多保留两条敌方攻击。暂停冻结投射物、持续危险区和精英冷却；转入首领战和战败时清空残留攻击。

## 首领时长

五位首领保留各自技能组，以180秒为耐久调校目标，三分钟后才开始强化压力，不做超时直接失败。基础武器等级会影响入场耐久估算，机库永久伤害/射速升级不会抬高首领血量。常规3–7台、W2–W4与三种机型的模拟样本约155–190秒；使用核心和模块的样本通常更快。满配机库允许明显缩短战斗，避免升级收益被抵消。

## 单位与反制

| 单位 | 行为 | 玩家收益与反制 |
| --- | --- | --- |
| 巡逻机 | 捕获玩家轨道，预警1.2秒后两连射 | 提前击破可打断；已发出的炮弹继续飞行 |
| 突击蜂 | 两列小编队；接近后预警1秒、冲锋0.6秒 | 低血量适合连续清除；冲锋模型和判定位置一致，命中后退场，避免重复碰撞 |
| 狙击哨 | 锁定一列，预警1.8秒，随后发射高伤单发 | 换道后不会重新追踪；蓄力期间击破可取消攻击 |
| 轰炸机 | 预警1.8秒后向两列投弹，飞行1.2秒 | 第三列可躲避；击破会对自身轨道、距离6进度以内的可见敌人造成6+武器级别×2伤害，可触发连锁爆破；不跨列 |
| 维修机 | 每1.4秒为同列、距离6进度以内的一名受伤友军恢复2点生命 | 优先击破可终止支援；不能自疗、复活或超过最大生命 |

攻击调度同时最多两个任务，综合未来约3秒到达的单位碰撞保留逃生空间；奖励门即将通过时，不再向该奖励列安排新攻击。已显示的预警和已发射弹道不会为玩家换道重选目标。首领战入口、战败、重开清理旧攻击，暂停冻结模拟。

## 连续击破

- 2.5秒内再次击破延续连击；3/6/9连击积分倍率依次为1.25/1.5/1.75，上限1.75。
- 每三次连续击破恢复2点核心生命，上限为当前最大生命；不改变攻击间隔、局内伤害或开局机甲数。
- 击破时立刻移除实体，并分别播放短促爆炸和连击数字。爆炸事件最多保留10个；持续0.7秒，避免多杀只剩最后一处反馈。
- 蜂群两列错位、支援兵后排站位；接近玩家时纵向间距逐渐收敛，避免远处模型提前造成接触伤害。射击、近战、受击和爆破共用实体坐标。
