# 三路机甲玩法与验证

## 关卡

每关道路运行约116–122秒，随后进入以180秒为调校目标的独立首领挑战；总时长以约5分钟为目标。前线新增三组主题怪潮、三名精英与护卫，详见 ENEMY_WAVES.md。首领战按血量决定胜负，不因短倒计时结束而失败。通关解锁下一关，首页可重玩已解锁关卡，解锁进度与机库一起保存。进入下一关重新按机库配置开局，不继承上一关临时强化；所有机型固定单机甲开局。

| 关卡 | 差异 |
| --- | --- |
| 工厂出口 | 基础无人机，单轨道首领攻击 |
| 无人机走廊 | 移动无人机、前后成组目标，首领每轮移位 |
| 装甲封锁线 | 带减伤装甲的目标，首领周期性护盾 |
| 能量风暴区 | 两段临时干扰区域，双轨首领攻击 |
| 重装机甲基地 | 移动与装甲组合、更强首领和双轨攻击 |

## 战斗

- 模拟步长 100ms，齐射间隔保持 400ms。每台机甲独立产生一发子弹，发射位置在开火时保存；子弹飞行 200–800ms，由距离决定。CSS 负责中间帧平滑显示，不决定命中与伤害。
- 只锁定同轨道最近的可见目标；障碍挡住后方火线。移动目标离开原轨道后，已发出的定向弹不会跨轨命中。目标被队友提前摧毁时，普通弹继续完成无伤害飞行；穿透弹可继续寻找原轨道后方目标。
- 移除原有的目标最大血量比例伤害上限。武器、数量与临时强化参与实际伤害计算；敌方装甲为每发固定减伤，至少造成一点有效伤害。
- 0/1级：基础直射／脉冲炮；2级：同轨道穿透一次，后续伤害为65%；3级：命中后附加2秒灼烧，每0.5秒触发，重复命中刷新持续时间；4级：每四轮齐射释放一次3倍伤害爆发。
- 护盾抵挡一次有效攻击；装甲提供每级两点可消耗防护。装甲不是永久免伤，维修可以恢复防护余量。
- 首领战使用独立的登场、预警、弹幕、恢复、召唤、半血展开、击破和战败阶段，完整时序与五关区别见 [BOSS_FLOW.md](./BOSS_FLOW.md)。
- 登场与半血展开各1秒，第一轮只发一枚预警炮弹，弹幕结束后有1.8秒弱点输出窗口。召唤物与弹幕错峰，不叠加处理。
- 战斗180秒后逐步强化攻击，预警始终存在；取消12–15秒未击破直接失败的旧规则。
- 首领归零立即清场，播放1.6秒击破动画后结算；小队归零则播放1.8秒战败演出。暂停会冻结模拟、动画选帧和战斗状态计时。


## 补给

每个时间点只出现一个门，轨道随机。首两个门分别提供机甲和武器，Boss 前两个补给点保证为奖励；惩罚不会连续出现。门的轨道避开邻近障碍碰撞位置。

门采用AI绘制的实体立柱、内侧面和地面底座。门槛位置到达脚下64%接触线时结算一次；只有真正穿过相同轨道才播放收集帧。机甲、门和敌人按地面远近排序。空射子弹在地图道路远端收束消失，避免飞到建筑与天空上。

额外门包括：下一轮齐射3倍强化、8秒过载（伤害+50%）、6秒干扰（武器暂降一级后恢复）、护盾、维修与装甲。界面保留简洁图标和剩余时间，文字播报只显示首领登场与战败。

## 玩家生命与首领突袭

玩家有独立100点核心生命条，受击显示扣血、闪红与短暂保护，护盾／装甲吸收显示蓝色反馈；机甲数量仍决定齐射数量。生命或机甲归零进入战败演出。首领交替使用轨道炮、连续弹幕、单列突袭、二阶段双列横扫，突袭提前1.6秒锁定轨道并保留安全通道。首领入场一次性校准生命，常见装备模拟击败时间74–179秒，详见 BOSS_FLOW.md。

首领会在每轮攻击后的恢复窗口随机换道，0.5秒内平滑移到另一个轨道；攻击预警后锁定位置。首领生命条固定在顶部HUD区域。

## 五关首领专属机制

铸炉监工使用熔岩封路与重锤突袭；苍穹蜂后召唤可击落蜂群、连续发射蜂刺；赤铁堡垒用可击破重盾封锁与盾阵冲撞；风暴先知连续逐列预警释放能量束；星核帝皇双列交叉炮改变安全缺口，二阶段加入双列横扫。仅首关共用单炮教学，其余首领开场即展示专属招式。代表性装备模拟约73–161秒，最新规则与验证数据见 BOSS_FLOW.md。

## 普通敌人也会主动攻击

道路无人机预警后锁定一列发射两发能量弹；路障蓄力释放沿地面推进的电磁冲击波；小机器人蓄力后向前扑击。三种攻击都可换道躲避，蓄力阶段可被击毁打断。无人机已经发射的弹道会保留，击毁后不会补发下一弹；机器人扑击结束退场，避免重复接触扣血。攻击时序、伤害与验证见 BOSS_FLOW.md。

## 三类机甲

机库可免费切换脉冲先锋（0.4秒高速低伤）、重锤泰坦（1秒慢速高伤）与疾刃游侠（0.7秒近战挥刀）。机型选择会保存，首页和局内外观同步。近战需要敌人进入范围，换道会取消尚未完成的刀击；近战首领进入近距离战场。详细机制、美术和验证数据见 MECH_CLASSES.md。

## 机库改装 v2

所有机型、所有永久改装等级固定开局1台，局内仍可通过奖励门招募队友。武器、装甲、动力核心均可消耗零件升级至5级，三种机型通用；动力核心只提高伤害与攻击频率。机库显示当前出击属性、下一等级对比、费用和零件不足状态，支持装卸和一键装配。旧核心等级保留为动力核心等级，不再增加开局数量。详细费用与迁移规则见 GARAGE_SYSTEM.md。

## 连续关卡与教学

每关必须正式击败首领并完成结算，才会解锁下一关；选关和开始／重开／下一关同时校验连续完成记录。新玩家首次出击先进入六步训练场：换道、对线射击、奖励门、危险躲避、首领预警和反击、机库与解锁说明。训练有动画示范、文字目标与实际操作判定，可重试、暂停和重温；训练完成不发放零件、不解锁第2关。旧进度迁移与验证见 TUTORIAL.md。
