# 动作、特效与显示时序优化 v20

## 实际观察与问题

通过本机实时运行页面观察了跑图、力量机开火、首领战换道与暂停。原首领战的射击条使用 0.4 秒、八帧无限循环并带负延迟，容易在待机/攻击间回跳；部分炮口闪光落后于炮弹创建。移动无人机的轨道值是离散切换，原显示依赖 CSS 过渡。大量连锁击杀会同时出现许多文字和发光。

## 本轮调整

- 保留 100ms 战斗 tick、原射击频率、伤害、碰撞及关卡逻辑。新增只负责显示的帧间采样；普通画质目标约 60Hz，低画质约 30Hz。实际可见帧率受设备和浏览器节流影响，不把后台读数当作设备性能结论。
- 炮弹保留每台机甲的独立发射点，逐帧绘制捕获轨道内的轨迹；目标换轨后不把已发出的弹体拐进另一条轨道。空射、升级弹体、首领炮弹和近战刀光也使用同一显示时序。
- 待机、射击、闪避条按实际动作进度选帧，去掉独立无限循环。加入轻量后坐力和收尾；炮口闪光对齐实际发射 tick，并直接使用每枚炮弹捕获的独立发射坐标，移除重复的头顶闪光。闪避显示跟随原平滑队形位置，不改闪避窗口。
- 重型机甲跑图时保留连续腿部步态、上身开火叠层平滑进出；近战保留完整挥刀轮廓，避免遮掉长武器。继续使用已有原画与精灵素材。
- 无人机换轨约 0.2 秒平滑衔接；移动敌人、突击蜂冲锋、小机器人扑击、首领位移、门、任务目标及外置部件在两个 tick 之间连续绘制。
- 击破粒子、爆破和完美闪避光效按显示进度淡出；减少同屏重复连击文字，减弱队友护盾遮挡。低画质限制击破位图数量并减少滤镜，攻击/危险预警继续保留。
- 暂停、剧情与后台切换停止显示循环，冻结场景动画；离开页面取消待执行帧。显示采样不修改原战斗状态，也不触发额外伤害、奖励或消除。

## 验证方式

- 实时观察入口：`http://127.0.0.1:5180/src/games/toybot-breakout/motion-review.html`。使用真实游戏组件，可切换三机型、跑图/首领战、换道、设置及暂停；不保存机库、设置、剧情或奖励，禁止在预览跳转到机库/首页。未注册为生产游戏路由。
- 开发观察条显示的是 JS 绘制采样频率、单次写入耗时和对象数，不是 GPU 合成帧率测试。前台曾观察到约 60Hz；隐藏/被遮挡的浏览器会节流，因此不宣称所有设备达到 60fps。
- 暂停前后实际 DOM 绘制计数与相位保持不变，验证了停止绘制。低画质调度通过可控帧时钟验证约 30Hz，停止后不会残留回调。
- 156 项全量模拟测试通过，包含原玩法，以及采样边界、状态不变性、八帧单次播放、连续侧闪、独立炮弹起点、目标换轨不追弹、无人机过渡、扑击预测、低画质调度和停止清理。
- 相关 ESLint 与生产构建检查。应用类型检查保留 App.tsx / LogService.ts 原有的三处共享代码错误；本轮未改共享代码。

新增运行代码只位于本游戏目录，无新依赖、全局监听或网络服务。绘制循环只写场景节点样式，每个战斗提交重新收集节点，避免逐帧 React 全树重绘。
