2026-11-11，按用户截图授权进行战场、信息层级、首页和局部打击反馈优化，并增加关卡推进难度。V56固定标签toybot-breakout-v56-baseline仍指向96a1f77a，不移动标签，不新增系统、不替换整体画风、不改存档结构。

## 战场与页面

- 守护者行动跑图时显示推进百分比，距首领5进度单位内才出现首领和警告；正式首领战才显示完整首领血条。25个前置小关仍无首领。暂停沿用当前阶段，胜利/战败衔接不受影响。
- 首领战顶部隐藏重复标题，将空间让给12px名称和11px生命数值；320宽使用11px名称。关键攻击名恢复到上方显示，普通小怪仅在蓄力时显示名称；精英、地面危险、HP条与无障碍目标说明保留。首领部件仅当前瞄准部件显示名称，减少重叠。
- 已完成的小关折叠在可展开列表内，仍可重玩；当前行动独占一行。精简重复任务说明；暂停/胜利保留一个主要操作。320×640九语言出击按钮下沿608.25—631.25px，均完整可见，无横向溢出。

## 难度梯度

按地区与小关固定计算difficultyV57，不根据当前装备、生命或临时强化动态抬高难度。

| 项目 | 递进规则 |
| --- | --- |
| 五个首领本体HP | 2300、2600、2800、3000、3200；超载协议仍为1.2倍 |
| 前置怪潮 | 保留每关原有72—168名数量梯度、三波编排与撤离路线 |
| 特殊敌人 | 小关2引入更多专精单位，小关4增加第三个专精位，后期地区进一步扩充；普通潮群HP不额外膨胀 |
| 小型精英HP | 按关卡进度阶梯最高约+30%，向上取整；首次精英仍在第三小关 |
| 敌人射击/召唤物伤害 | 第一地区保持基础值；随后逐步增加，最终地区守护者行动最高+16% |
| 已学习攻击预警 | 按进度最多缩短0.3秒，最低1秒；首次接触保留原预警和额外0.8秒教学保护 |
| 精英再次攻击 | 逐步缩短既有再装填间隔，最终约为原间隔87.5%，最低3.2秒 |
| 首领节奏 | 第一轮保留原节奏；后续地区恢复间隔逐步缩短，二阶段更紧凑，标准协议仍有至少1.9秒反击窗口 |

首领保留各自专属技能组与破坏部件效果；安全排程不变，警告锁定后不追踪玩家，不用三轨同时封死来提高难度。具体小关、护盾机制、获取装备仍影响实际战斗时长，不能把血量增加当作难度唯一指标。
