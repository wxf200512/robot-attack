# V64 混音、首领配乐与完整机甲跑射

## 当前实现

保留 V56 机甲完整外形。用户否定的分离部件拼接试验已撤下，未进入本提交。三机型跑图采用完整轮廓的32帧补间（两套装备层、8×8 atlas），保留持枪右手，修正左右腿交替循环，清除离散透明杂点；不在运行时拼接、缩放四肢。肩腰反向联动由1.8度减至0.75度，射击仍叠加本机实际开火的局部后坐力，距离驱动的迈步时钟不因射击重启。首领战继续使用各机型既有站姿、攻击、闪避模组，不播放跑图帧。当前是2D光流补间，不是3D动画或真人动捕；轮廓遮挡、透视与自然程度仍有2D限制。

射击改为短促枪械录音采样与既有机械层，普通连射100ms、重炮230ms，减少拖尾。采样包络由0.88降至0.60（强化0.70）；武器/命中总线由0.8/1降至0.5/0.55。配乐底床0.75、独立音量比例0.85；普通命中、击破和强化不反复压低音乐，仅受伤、重要警告及核心释放短暂避让。静音/暂停会清理未结束采样并复位总线增益。未改变射速、伤害、碰撞判定或关卡值。

普通关保留 V62 柔和配乐；五个首领各有独立选段、节奏/EQ处理后的文件（熔炉重鼓、蜂群弦乐、壁垒慢鼓、极性管弦、终局紧迫重奏）。沿用CC0母带，并非五首原创作曲。循环60/64秒、0.65秒过渡；预取提前至50%进度，剧情交互期间配乐降到45%而不是完全暂停。真正暂停仍停播并从保存位置恢复。五首MP3总计2499399字节；六个当前曲目合计低于4MB，运行仅保留当前和将遇首领的解码缓存。

## 来源与重制

- 枪声：Vincent Sevedge，Tabasco 上传，https://opengameart.org/content/gunshot-sounds 。页面标注CC0，但下载包原文标注CC-BY3.0；本项目按更严格的包内CC-BY3.0保留署名、链接和改编说明，玩家可在声音设置的“音频授权”展开查看。母带/原许可位于art-source/audio-v64，裁切、EQ、包络和响度处理见audio-v64.json。
- 其余音效仍沿用V63 Kenney/qubodup CC0母带；配乐母带与CC0来源见art-source/music-v62/sources.json。
- 完整机甲母图仍是已保存的V56原件；新补间制作脚本和说明在art-source/run-v64，SHA/源帧记录见run-v64.json。未采用失败的拼接贴图，也未将竞品的音频或人物素材复制进项目。
- 制作工具是现有独立Python环境中的Pillow/numpy/scipy/imageio-ffmpeg；游戏未新增npm依赖。脚本命令为python build.py <实际仓库绝对目录>，不需生图API或运行期音频服务。

## 验证与边界

416项回归通过；TypeScript、相关ESLint与git diff --check通过。浏览器实际游戏使用V64完整跑图atlas，三名队员，未发现框架错误或运行时console error；内置浏览器后台会降频，未把该环境的帧率当成真机性能结论。浏览器真实音频引擎普通关→首领3切换、暂停/恢复通过；六首配乐均解码为60/64秒。真实混音器离线24秒包含134次攻击/命中并叠加普通关与首领BGM，峰值0.2362097055，无削波。试听与原尺寸动作GIF、浏览器截图及原始校验JSON保存在本地交付目录，未进入游戏包。
