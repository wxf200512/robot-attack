# 1–5项体验优化验收（2026-11-03）

## 1. 手机布局与输入

- 首页、机库、训练、暂停、设置和结算适配窄屏及安全区；小屏结果页压缩徽章和留白，主要按钮保持可见。
- 正式战斗改为相对拖拽和半轨阈值，边缘反向移动立即响应；过滤轻微抖动，处理指针捕获丢失。
- 离开窗口、隐藏页面或打开设置会暂停；返回后由玩家继续，避免后台战斗造成损失。
- 首领血条与核心生命、换道按钮分区，减少遮挡。

## 2. 图片和加载

原始图片从部署目录移入 art-source，仍可重新加工。运行时统一使用 public/games/toybot-breakout/optimized。地图及机库背景使用JPG，精灵和特效保留透明PNG；首页重装、疾刃机体采用单独正面条带。

部署图片总量由59,274,095字节降至20,298,771字节，减少65.8%。这是所有图片总量，不等于首屏下载量。首页不挂载隐藏战斗场景；首领、下张地图分别在进度65%、80%后预热。

复现：在仓库根目录执行 `powershell -ExecutionPolicy Bypass -File src/games/toybot-breakout/optimize-assets.ps1`。无需安装图片处理依赖。

## 3. 永久改装成长

首领生命估算使用机型基础射速和基础伤害，不再补偿永久伤害、射速改装，保留局内人数及武器等级对战斗强度的影响。机库显示永久伤害增幅和攻击间隔变化。

固定5台、局内W3、同策略模拟：基础脉冲第1关74秒、第5关114.7秒；满级永久改装24.3秒、40.4秒。重装和疾刃也验证升级缩短击败时间。基础战斗仍以1–3分钟为目标，满改装可以更快。

## 4. 声音与反馈

增加三机型攻击、命中、击破、护盾、受伤、预警、门、改装及胜负音效；同一轮小队齐射合并发声，限制同时声部。音效由Web Audio合成，无额外音频下载。首次手势后解锁，后台及静音时停止发声。

声音与画面设置包含静音、音量和自动/流畅/高画质，独立本地保存。流畅模式减少装饰滤镜，保留弹道、伤害和预警。增加重炮后坐力、近战随动等反馈。

## 5. 教学节奏和续训

保留六步实际操作任务；目标文字常驻，额外解释可展开。门与危险接近速度由0.9调至1.2，减少等待。每步保存安全检查点，退出或刷新后回到未完成步骤入口，不恢复危险实体和旧弹道；完成后清除检查点。训练不改变正式奖励、零件或关卡解锁。
