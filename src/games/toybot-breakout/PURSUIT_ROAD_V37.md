# V37 锁轨追袭与前进路面

普通路段突击蜂会预警锁定玩家轨道，随后变道冲击。普通射击型敌人保留原有射击，存活完成攻击后进入一次追袭；若当前攻击压力占满两路，则等待安全窗口，保证逃生轨道。维修型也可在靠近后发起冲击。精英保留各关特色技能组。

首领的机器人、可破坏路障会在短暂现身后锁定玩家预警，未击破则横移扑向该轨道。即将到期的护盾节点、汲能节点、能量球、符印和移动墙体也会先预警再冲击；蜂卵仍保留孵化特性，由孵化单位执行扑击。地面能量场与不可击破炮弹保持自身行为。预警后不追踪重新换道的玩家；击破源头会取消对应身体攻击。冲击由攻击终点结算一次，原寿命到期不会再追加第二次伤害。

`pursuitV37.ts` 提供真实身体位置和当前碰撞轨道。横移模型、自动瞄准、子弹锁轨检查、近战、受击位置均读取同一份移动状态，不仅移动美术。预警中的召唤物固定蓄力位置，避免寿命插值产生小幅抖动。

五张AI路面纹理替换为可滚动的独立透视地面层，城市远景保持稳定。路面滚动由真实推进距离与单步插值驱动，不使用独立墙钟CSS循环，因此整备减速会同步变慢，暂停和首领战停止。使用两条简约透视分隔线形成三路，移除新旧引导线叠加。减少动态模式关闭滚动。

原图、提示词、机械切图脚本分别为art-source/road-tiles-v37.png、ROAD_PROMPT_V37.json、optimize-road-v37.py。五张运行时WebP纹理各小于100KB。只修改游戏目录，无新增依赖。

验收：269项测试通过，含召唤物预警中击破、跨轨中途拦截、锁轨后躲避、扑击只命中一次、全部关卡通关及保留逃生轨道。ESLint与生产构建通过。全项目TypeScript仍只有共享App.tsx/LogService.ts已有3处错误，本轮游戏没有新增类型错误。

浏览器390×844实际录制路面前进、召唤物跨轨扑击和普通小怪跨轨冲锋。小怪坐标从约65%移动至32%，召唤物从约36%移向玩家右路；命中后消失且护盾格挡只消耗一次。首领战连续采样地面偏移均为224px，保持停驻；控制台无error。320×640检查无横向溢出，路面层1个、分隔线2条。动图由真实游戏截图编码，左侧路段前进，右侧首领召唤物突袭。未进行Facebook或真机环境验收。
