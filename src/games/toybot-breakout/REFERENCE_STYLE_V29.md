# V29 参考画风落地

采用用户确认的工业玩具机甲参考图，实际战斗界面使用生成素材，保留既有三路玩法。

原图和清理后的地图均保存在 `art-source/`；运行素材在 `public/games/toybot-breakout/optimized/`。提示词与设计说明见 `ART_PROMPTS_V29.json`，机械处理脚本 `optimize-v29.ps1`。V29 机甲动作草稿保留用于追溯，实际动作已由 V30 替换。

## 与参考图逐项对照

1. 明亮蓝灰钢板路面、橙色工业建筑、清晰天空；五关使用五张独立地图。
2. 白色/藏蓝圆润玩具机甲与矩形发光背包，取代尖锐细长的旧机体。首页和机库组合预览使用同画风的三机型正面图集。
3. 第一关改为圆形橙色熔炉首领、腹部火炉与双烟囱，置于远端；其他关保持各自首领。
4. 门为实体外框、发光门洞和落地底座，随接近缩放；门和触发阈值共同经过地面投影，避免浮在机甲上方。
5. 顶部紧凑生命条不再遮住首领主体，底部为圆形青色技能键、左生命和右小队屏幕。
6. 清理地图原有错误轨道，使用与场景投影对齐的两条原生地面分隔线；每台机甲的炮口、飞弹、命中反馈使用相同坐标投影。

最终通过原生 399×711 视口截图与用户参考图直接比较。它保持参考的色彩、材质、主体造型和驾驶舱构图；仍按真实玩法把小队控制在一个队列，没有伪造参考图中固定横跨三路的三名角色，也不把参考图的 480 生命值写死。门图标显示当前实际奖励而非固定礼盒。远端首领为不可攻击的预览，实际战斗与警告按既有流程开启。

V30 进一步解决用户指出的动作重影与机型动作混用，详见 `ANIMATION_V30.md`。
