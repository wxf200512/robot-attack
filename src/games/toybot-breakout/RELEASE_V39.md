# V39 提测交接：15项作战与门即时回收

状态：本地提测版完成；尚未完成Facebook平台/真机验收，不标记为正式上线通过。

## 本轮内容

保留五个剧情区与各自守护者，新增十个独立短关，共15项作战。短关复用对应地区地图、敌群和精英配置，以明确目标和较短节奏提供额外内容，并非增加十张新地图。

| --- | --- | --- |
| 工厂出口 | 灯芯运输线：击破8台敌机 | 熔炉守门阵：击破1名精英 |
| 无人机走廊 | 猎蜂拦截：击破12台敌机 | 蜂巢护航阵：击破1名精英 |
| 装甲封锁线 | 盾卫清障：击破10台敌机 | 重装督军阵：击破1名精英 |
| 能量风暴区 | 电涌前哨：击破12台敌机 | 极性执法阵：击破1名精英 |
| 重装机甲基地 | 近卫清场：击破14台敌机 | 裁决封锁阵：击破1名精英 |

短关从一台机甲出发，有独立目标、进度、暂停、重试和结算；抵达终点仍需完成目标并存活。每区前哨完成后解锁精英短关，未解锁的剧情地区不能进入。短关完成不冒充首领击败，也不会提前解锁下一剧情区。

首通增加1零件，单次短关最多4零件，复玩不重复发首通奖励。新增sortieClears字段兼容旧机库存档；没有新字段的旧存档不会被清空。剧情、升级、波次、三机型独立动作和原有首领战保留。

门在gateResolved置位的同一渲染周期直接卸载；奖励只应用一次，保留独立强化反馈。漏过的门同样移除，暂停不会重新显示已消费的门。补齐游戏列表的真实封面，并为短关调整按钮、目标与奖励说明。

## 检查结果

- 279项测试通过：277项游戏回归、2项发布脚本检查。含五关主线、三机型、全部十个短关的30组完整通关采样、存档合法性、奖励、目标失败、重试、暂停与门卸载。
- 短关采样：普通三机甲W2队伍，前哨40.4秒、精英59.6秒。浏览器从首页实际开启猎蜂拦截，单机出发、途中招募，约38秒击破22台并结算4零件。该实测不等同于所有初始装备都已完成难度验收。
- 修改的TypeScript/TSX文件ESLint无告警。Vite单游戏生产构建通过。
- 390×844、320×640检查无横向溢出；窄屏出击可见，底部机库按钮可滚动到并使用。门真实DOM数量由1降到0，交互线同步降到0；强化反馈仍显示。
- 实际模板游戏列表已显示新封面，可进入游戏并返回列表；控制台无error。
