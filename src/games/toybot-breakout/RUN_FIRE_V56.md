# V56 全身跑射与上半身联动

三机型分别生成完整后视跑步原画，基础与强化皮肤分开。原PNG及提示词在art-source/run-whole-*-v56.png与run-whole-v56-prompts.json；运行时图集为1536×768、8列4行。不是只换腿：头、肩、手臂、胸腔、骨盆一起来自新全身画面。持枪侧朝道路前方；近战保持独立持刀与攻击模组。

图集的16时间槽不等于16张全新姿势：脉冲从原画选取13个姿势，重复经过中间过渡姿态，排除出现多余左手炮的原画；力量使用16姿势重排，近战保留16槽。具体来源和映射在gait-v56.json。每种皮肤只用一套缩放，按头部定位，避免每帧以脚部包围盒缩放导致呼吸膨胀。

runTorsoV56.ts用与腿部相同的道路相位驱动髋部轴心的肩部反向摆动：最大1.8度、横向0.85px，重型幅度65%。身体的互补上下遮罩使用同一张图同一帧，不叠化两个完整角色，不额外开动画计时器。未加入整机跳动。射击冷却不重置步态；首领驻足/闪避、近战挥刀、暂停与低动态模式会停用该联动。

三人/四人小队由原58—82px收至52—64px，所有成员等大。各自捕获的枪口仍独立，子弹/核心光束发射高度随同尺寸更新。常驻金色装甲翼停止显示，装甲由角色原画表现；保留真实受击闪光与护盾破裂，护盾常驻光环缩小降低亮度。

复现：Python+Pillow执行assemble-gait-v56.py，只读取仓库内原图并重新打包透明无损WebP。不会改源码、不会访问生图服务、不需要API密钥。gait-v56.json记录来源、映射、缩放、SHA256。

验证：自动回归391项；TypeScript、修改TS/TSX的ESLint、125运行素材路径无缺失；390×844和320×640本地浏览器检查三机型、首领驻足层隔离、暂停/恢复。连续截图确认步态与肩部变换推进、前后排分离。后台浏览器截图不是实际手机帧率指标，动作自然程度仍需玩家主观复核。没有执行Facebook或真机测试；本轮不重打历史正式提测包。
