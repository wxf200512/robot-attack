# V52 双腿交替奔跑

替代V50的旧帧排序与运行时锚点补偿，撤销V51整机正弦起伏、透视倾斜和落脚尘。V48原跑图在脉冲等机型中缺乏左右腿交换姿势；增加整体摇摆不能修复单腿跳。

使用内置imagegen分别生成三机型的后视腿部动作，原图和完整提示词保存在art-source/run-legs-*-v52.png、run-legs-v52-prompts.json。保留V48已有上半身、枪/刀及基础与强化装甲，只在固定髋部接缝下装配新腿部。近战原图第二行仍重复左腿支撑，所以只对腿部做对称半周期装配，头、手、武器不镜像。常规图像裁切、缩放、透明合成，不绘制替代角色。

每种机型为8个迈步姿势，映射到16个时间槽，每姿势保持两槽；不是16张独立原画，不插入叠化重影。轻型与近战一周期0.8秒，重型0.96秒，跟随道路推进距离；成员错开相位，暂停冻结，低动态停帧。首领战仍用原有独立战斗素材，不改变射击间隔、队形、逻辑枪口、伤害及碰撞。

复现：在仓库根目录执行Python + Pillow脚本 `python src/games/toybot-breakout/assemble-gait-v52.py`。输出三张1536×768无损透明WebP和gait-v52.json。脚本验证上半身各帧逐像素一致，并验证脚掌前后深度差在左右两个方向都出现，防止再次整周期单腿支撑。原V48素材保留用于上半身来源和历史验收。

验证：356项自动回归、TypeScript、修改TS ESLint、125个运行时素材路径检查、生产构建；390×844/320×640本地浏览器检查三机型、强化多人小队、暂停冻结、首领切换。录制实际连续游戏截图供步态主观评审。录屏采样不代表帧率基准；实体手机与Facebook尚未验证。
