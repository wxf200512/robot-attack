# V50 跑动小范围调整

保持V48三类机甲、两档装备与全部图片字节不变。本轮不接入此前撤回的V49素材，不改界面、存档、射速、队形、碰撞或首领动作。

跑动周期从脉冲0.64秒、重装0.88秒、战刃0.56秒，分别调整为0.96、1.12、0.88秒（正常道路速度）。改从实际推进距离采样，精英整备减速时步频同步降低；成员采用不同步相，停止与暂停保留原冻结机制。

读取现用V48图集，以背部核心局部模板计算整帧平移注册，最大偏移10/192格宽高；不拉伸肢体、不裁切或重绘图片、不叠化两具身体。百分比平移随机体显示尺寸缩放，仅在run图集使用，首领站姿/射击/侧闪维持原逻辑。取消跑图期间炮击对整个身体的独立后坐，炮弹、炮口和真实射击节奏继续原有表现。

对两排帧的接序分别分析，不强行共用顺序。脉冲采用相位校准的交错序列，基础/强化两档的平均与最大相邻下半身图像差均下降；重装/战刃重排更差，保留原顺序。这只是位图连续性指标，不等同于真人对自然程度的评价。

`analyze-run-v50.py`只读现用图集，重建runRegistrationV50.ts和run-registration-analysis-v50.json；需开发环境已有Pillow，不新增游戏依赖。报告保留图片SHA256，回归会校验图片未变。开发用“道路滚动”样例恢复正常冷却，避免1000步哨兵值让近战预览误显示攻击；不读写玩家进度。

验收：354项测试通过；TypeScript、修改TS/TSX ESLint、生产构建及122资源URL核验通过。新测试覆盖推进/减速、16帧完整循环、射击不重启步态、注册边界、素材字节不变、暂停和低动态。

本地内置浏览器390×844、320×640：三种机型分别使用原有独立跑动图，三台机甲对应三个身体；暂停后样式与绘制次数不变；首领仍使用原arena图与像素后坐；无应用console error、Vite遮罩或横向溢出。录制24张连续实际页面截图并编码GIF供查看，截图不是性能基准。Facebook、物理手机与用户主观手感仍需实际游玩确认。
