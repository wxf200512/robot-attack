# 首页剧情展示：黎明重启

## 玩家流程

- 本版本首次进入游戏，自动打开四幕序章：星穹城 → 静默协议 → 火花苏醒 → 向黎明出发。
- 每幕使用 ImageGen 绘制的双分镜插画，正文、角色名与对白由界面排版，不烘焙进图片。
- 手动翻页、页码跳转、方向键翻页；随时关闭或跳过，回到首页。未关闭时刷新继续当前页。
- 读完后点击“进入机库首页”；再次打开从第一幕重看。关闭漫画不会自动开始战斗。
- 首页常驻“序章漫画”和“世界档案”，当前任务随选择关卡更新。
- 世界档案介绍城市、火花、米可、五区任务、守护者与战术。权限恢复状态读取真实 completedLevels，仅完成首领战与胜利结算才会改变通关进度。
- 阅读后点击出发仍走原有新手训练或正式游戏流程。

## 存档与容错

独立存档键 `toybot-breakout:story:v1`，保存版本、当前页、是否关闭和是否读完。与机库零件、关卡进度、设置及教学记录隔离。无效版本重置剧情记录；页码校验范围；禁用存储或存储已满时仍能阅读。

漫画插图加载失败时保留正文、翻页与关闭功能，并提供重新加载按钮。只预取下一幕图片；主战斗资源加载器不增加整套漫画。界面固定顶部导航与底部操作，中部可滚动，支持键盘焦点约束、Escape 返回和减少动态效果。
