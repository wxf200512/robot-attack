# 界面美术 v6

统一使用深蓝金属、青色能源光、象牙白结构，胜利用暖金、失败用珊瑚红作为状态色。功能文案与按钮保留为真实HTML，图片仅承担空间背景和装饰，便于移动端适配与文字清晰显示。

- 首页：新机库背景、中央机甲展示、五关选择格、任务卡片与主出击按钮；机库装备继续同步到预览机甲。
- 机库：统一空间背景与机甲预览、库存信息、三组模块卡片，区分已装配、可购买、零件不足；操作沿用原有购买、升级、装卸逻辑。
- 暂停：独立控制台式面板，展示关卡、进度、小队、核心生命；突出继续游戏按钮。
- 胜利：完整暖金反应炉徽章、任务完成状态、作战得分、零件收益、归队机甲，突出下一关；最终关不显示下一关入口。
- 失败：受损珊瑚红反应炉徽章、重整出击按钮与按首领特点给出的简短战术建议。

界面样式集中在 interface.css，使用游戏根节点限定范围，保留短屏滚动与窄屏规则、键盘焦点和减少动态效果偏好。游戏模拟、关卡数据和存档结构保持原有行为。
